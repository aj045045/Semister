**Q1: Answer the following in brief (Any THREE) - [3 Marks Each]**

**1. What do you understand by 'Cloud' in Cloud Computing?**
The term "Cloud" in Cloud Computing refers to on-demand availability of computing resources (like servers, storage, databases, networking, software) over the internet. These resources are managed by cloud providers and accessed remotely. It enables users to use IT infrastructure without owning or managing physical hardware.

---

**2. Discuss how Cloud Computing can be beneficial to University.**
Cloud computing benefits universities by:
- **Cost savings:** Pay-as-you-go model reduces hardware/software investment.
- **Scalability:** Easily scale resources for students, exams, research.
- **Collaboration:** Google Workspace, Microsoft 365 for sharing and group projects.
- **Remote access:** Students and faculty can access resources anywhere.
- **Data storage & security:** Centralized, secured data backup and access.

---

**3. Discuss any 3 services of Cloud Computing with a case study of real-time scenario and its application.**
- **IaaS (Infrastructure as a Service):** AWS EC2 allows launching virtual machines.
- **PaaS (Platform as a Service):** Google App Engine allows deploying applications without managing servers.
- **SaaS (Software as a Service):** Google Docs enables collaborative document editing.
*Case Study:* A university uses AWS EC2 for virtual labs and Google Docs for collaborative student assignments.

**Q2: Answer the following questions (Any THREE) - [5 Marks Each]**

**1. Explain briefly Service Delivery model. Briefly explain any 4 different AWS cloud services.**
**Cloud Delivery Models:**
- **IaaS:** Provides virtualized infrastructure (e.g., EC2).
- **PaaS:** Platform for developing, testing applications (e.g., Elastic Beanstalk).
- **SaaS:** Fully managed software (e.g., Amazon WorkDocs).

**4 AWS Services:**
- **Amazon EC2 (IaaS):** Launch and manage virtual servers.
- **Amazon S3:** Object storage service.
- **Amazon RDS:** Managed database service.
- **AWS Lambda:** Serverless compute service.

---

**2. What do you understand by Cloud Deployment models? Discuss each model briefly.**
- **Public Cloud:** Services are delivered over the internet (e.g., AWS, Azure).
- **Private Cloud:** Used exclusively by a single organization (e.g., government).
- **Hybrid Cloud:** Combination of public and private clouds.
- **Community Cloud:** Shared by organizations with similar needs (e.g., education, healthcare).

---

**3. State the actors and their roles in Cloud model.**
- **Cloud Provider:** Offers services (e.g., AWS, Azure).
- **Cloud Consumer:** Uses the services.
- **Cloud Auditor:** Ensures compliance and security.
- **Cloud Broker:** Manages service usage across multiple providers.
- **Cloud Carrier:** Intermediary that provides connectivity and transport.

**5. Why is cloud computing called variable cost computing model?**
Cloud services follow pay-per-use model:
- No upfront capital expenses.
- Cost depends on usage (compute hours, storage, bandwidth).
- Allows businesses to control IT spending based on demand.
